## 领域测试覆盖

测试直接调用 `terminal-uptime-domain.js`，使用明确事件时间和预期持续时长，包含：

- 营业内计算、夜间计划关机、午间分段营业、未来营业排除、尚未营业和休息日。
- Unknown 单独累计、30 秒离线与 Unknown 共存、1 秒离线不能舍入为 100%、观测冲突按 Unknown 处理。
- 接入时刻截断、接入前无日格、跨夜分日、指定日期覆盖前日跨夜延续。
- 保存前后版本切分、过去日期不因新计划变化、完整终端覆盖、恢复跟随。
- 换店历史权限、旧覆盖不带入新店、解绑后的授权内旧历史、只读和越权保存拒绝。
- 权威观测补齐后按当时计划计算；固定模拟观测刷新不改写已完成日期。
- 三个日历月边界及月末截断、非法日历日期、重叠和重复例外、Sunday → Monday 跨夜冲突。
- 夏令时开始日 23 小时、结束日 25 小时；时区版本变化不重新归组已完成日期。
- 本地保存并发版本冲突、配额失败不覆盖最后成功保存值。
