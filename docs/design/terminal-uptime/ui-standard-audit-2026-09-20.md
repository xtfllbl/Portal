## 已复现问题与建议修复

### 组织选择后丢失键盘焦点

- 步骤：打开 Organization，输入 `Europe`，按方向键及 Enter 选择 `Europe Direct · SP`。
- 结果：组织选中，门店候选联动，但 `document.activeElement` 为 `BODY`，键盘流程中断。
- 原因：`scripts/terminal-uptime.js:58–65` 调用 `filters()` 重建各下拉；`scripts/uptime-combobox.js:6` 删除旧输入，没有恢复新控件焦点。
- 建议：只更新受影响的候选列表，或在重建后恢复组织输入的焦点；继续按原约定等待 Search，不自动提交。
- 验收：鼠标和键盘选择均有效；Enter 后焦点仍在组织控件，Tab 能继续到 Store；仍有效的其他筛选条件保留。

### 页面滚动后下拉选项与输入框脱离

- 步骤：打开 Store 下拉，将鼠标移到页面主体并向下滚动。
- 结果：输入框底边从 y=230 移到 y=167，列表顶边仍为 y=234；原本 4px 的间距变为 67px，下拉仍保持打开。
- 原因：`scripts/uptime-combobox.js:49–53` 仅观察尺寸变化和最近的 `.up-dialog-body` 滚动，没有覆盖主页面实际滚动容器。
- 建议：滚动或调整窗口时更新位置；锚点离开可见区域时收起浮层，避免浮层悬空。
- 验收：主页面及弹窗内的下拉都跟随锚点；选项独立滚动，不被固定区域裁切。

## 可选增强，不作为当前硬性缺陷

- 七天日历可增加 Home/End 和 PageUp/PageDown 的日期、月份导航。当前已符合该页面原先确认的四方向键约定；新增快捷键需一并定义边界日期和跨月后的焦点行为。
- 可将选项的“键盘当前项”和“已选择项”增加更明确的视觉区分，例如已选项使用勾选标识；保持同一套图标与配色。是否改变现有下拉外观需先确定实验范围。
- 如选择更贴近 Select 的筛选外观，可让触发器保留已选值，在浮层中提供独立搜索输入；这是可选交互方案，会改变当前直接在控件中输入的方式，不应作为修复顺带替换。

## 研发组件映射建议

这里描述设计对应关系，代码仍为静态实现。

| 本页区域 | 参考模式 | 项目扩展 |
| --- | --- | --- |
| Organization、Store、Show | Select / 可编辑搜索选择模式 | 组织门店联动、待提交筛选条件；只接受已有选项 |
| Name or S/N | InputText 搜索输入 | 名称与序列号搜索 |
| 日期控件 | DatePicker | 选择截止日，自动带出前六天，沿用可见历史与时区限制 |
| 七天矩阵 | DataTable + 自定义日格 | 每日百分比、状态和时间条；日格进入详情 |
| 日详情 | Drawer + 明细表 | Payment Service 时间线、前后日导航、营业时间入口 |
| 营业时间编辑器 | Dialog + Select + 分段选择 + Checkbox | 每周营业计划、自定义时段、复制到其他日及继承规则 |

官方 [Select 文档](https://primevue.org/select) 可查搜索、选中状态及键盘关系。此次 `v4.primevue.org` 的 Select、DatePicker、Drawer 具体页面未能通过抓取读取，未将未经核验的快捷键清单宣称为 v4 硬性要求；涉及精确组件能力的后续实现应继续核对研发所用 v4 版本。

## 保留的业务约定

- 页面继续使用静态 HTML/CSS/JavaScript。
- 保留无顶部标签的一排筛选、单个 Search、无 Reset；编辑条件后统一提交。
- 保留七天窗口及历史查询，不改为自由日期范围。
- 仅统计 Payment Service，按终端当地日期和对应营业时间解释结果。
- 保留 No data、Closed、Not enrolled、Upcoming 和 `—` 的不同含义，不合并为一种空态。
- 保留现有名称与 S/N 分离规则；本轮没有新增或改变领域术语，也没有需要新 ADR 的架构决策。

## 已确认的实验范围与修复结果

用户以“ok”确认推荐方案 A：只修复两项已复现缺陷，保留整体外观及筛选流程。下拉外观调整与日历快捷键增强不在本次范围。

实现：

- `scripts/terminal-uptime.js`：组织选择后只重建门店候选，保留组织输入和其他筛选控件，避免删除当前焦点节点。
- `scripts/uptime-combobox.js`：捕获锚点祖先的滚动及窗口尺寸变化；根据视口和祖先裁切区域判断锚点可见性，不可见时关闭浮层。销毁控件时移除滚动、尺寸及焦点监听，避免重复挂载残留。
- 修改发生在该页面引用的脚本中；HTML、CSS 和业务计算未改。共享下拉也用于营业时间编辑器，已补查该入口。
