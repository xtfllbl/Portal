# 厂商测试卡作为独立测试业务

2026-10-21 决定：厂商出厂测试使用独立的 Test Card 业务，在 Paywizard Maintain 设置 Test Cards 菜单及专属 Transactions 查询页面；测试卡、测试交易及经营统计与正式储值卡业务隔离，无须为厂商创建生产服务商、商户和门店。已有储值卡能力可作为复用基础，但不得因此将测试交易混入生产交易系统。测试余额是测试额度，交易实际扣减额度并触发出货，不形成厂商应收或结算款。这样既能复用已有交易能力，又不要求厂商执行生产开户流程。具体系统部署与存储方案尚未决定。

本次明确复用已有储值卡支持的交易类型，取消此前厂商库存 MVP 对测试退款、冲正的额外排除；测试卡授权一家顶层 UPT 厂商且允许编辑。详见[测试卡系统设计基线](../design/test-card-system.md)。

终端测试资格以厂商库存经历和门店绑定边界定义，不能等同于当前是否在厂商直属库存；终端流转到贸易商后，从未绑定任一门店时仍允许测试。曾进入多家厂商库存的终端以最近一次厂商归属受理；普通贸易商间流转不改变厂商归属。首次门店绑定即结束测试资格，之后解绑也不自动恢复。卡片改换厂商后保留余额及原交易归属，但原厂商交易仅可查询，不再允许退款、撤销等后续操作。Transactions 后台页面仅查询测试交易，不提供发起金融交易的操作。
